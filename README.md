# Wikker

### Making knowledge more discoverable.

Wikker is a scrollable Wikipedia discovery app focused on interesting facts, strong hooks, great images, and personalized content.

## About

I'm a huge fan of [Xipedia](https://github.com/rebane2001/xikipedia) and think it's a fantastic idea. I just felt it was missing a little styling and visual polish.

Wikker is my attempt at exploring that idea further — with a more modern interface and a stronger focus on content presentation and discovery.

The entire project was **vibecoded from scratch** and does not reuse code from Xipedia.

It's nowhere near as well executed as Xipedia (yet), but it's a fun experiment in making Wikipedia a little more addictive to browse.

## Inspiration

Inspired by the concept and idea behind **Xipedia** by [rebane2001](https://github.com/rebane2001).

Xipedia is the original inspiration for this project and deserves credit for the core idea of turning Wikipedia into a personalized scrolling feed.
